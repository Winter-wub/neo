Neo — หน้าตาแบบต่าง ๆ

เวอร์ชัน Kotlin native (ไม่ใช้ WebView) — ทุกภาพมาจากโค้ดวาดตัวจริงของแอป หน้า pixel 32×18 สีมิ้นต์บนพื้นดำ ขยายแบบจำนวนเต็มให้คม

หน้าตาทั้ง 12 แบบ

เรนเดอร์จากฟังก์ชันวาดหน้า (Face.render) บน Mac

ไอคอนการ์ด

16×16 pixel แสดงบนการ์ดคำตอบ

แอปจริงบน Android emulator

ตั้งจอเท่า Galaxy A7 (2018) 1080×2220 แนวนอน — ขีดเขียวมุมซ้ายล่างคือแถบระดับเสียงไมค์

ตรวจแล้ว

  • build + lint ผ่าน, unit test 23 ข้อผ่าน
  • หน้าเต็มจอ การลูบ และการ์ดอากาศ ทำงานบน emulator
  • ภาษาไทยบนการ์ดแสดงถูก

ยังไม่ได้ทดสอบ

  • บน A7 จริง (ความไวการสัมผัส สีจอ)
  • เสียงร้องและปากขยับตามเสียง (ปิดเสียง emulator)
  • ไมค์ถอดเสียงจากเครื่องจริง
